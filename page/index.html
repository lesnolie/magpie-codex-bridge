    ChatGPT 远程连接

    本机管理 Cloudflare MCP 适配器 · 默认仅六个只读工具

    开启一次后，插件将尝试注册当前 Windows 用户的登录自启项（无需管理员权限）。Magpie 运行时自动启用 48765，退出后关闭监听；无需每次运行 PowerShell。

    需要事先配置 Cloudflare Access、安装 Node.js 20+，且 Magpie 与 Cloudflare Tunnel 正在运行。不修改你的 Cloudflare 设置，Codex 工具需在本机单独开启。

    本地 Codex 集成（实验性）

    通过本机 app-server 创建任务、查询结果和取消任务

    确认允许本地 Codex 修改当前项目来源中的项目文件？Codex 可能更改或删除代码。此授权仅在启用 Codex 后生效，建议先备份项目。

    默认只允许任务修改当前 Codex 工作区；属于同一 Codex Desktop 项目的多个目录会自动纳入 workspace-write 范围。其他项目不自动获得写入权限。

    可用于 Codex Desktop 自身能操作、Magpie workspace-write 却被拒绝的情况。启用后不再由本插件覆盖 Codex 的沙盒模式；Codex 实际权限取决于本机 Codex CLI 配置和版本。它可能允许修改当前项目以外的文件，需额外确认。

    确认使用本机 Codex 的权限配置？若 Codex 本地设置为完全访问，ChatGPT 提交的任务也可能在本机获得更广泛的文件写入权限。仍禁止自动同意提权请求。请只在可信设备和可信项目使用。

    仅 Codex 项目来源且开启 Codex 写入权限时生效。撤销写入会自动关闭本地权限继承。

    需要在 Windows 上安装可执行的 Codex CLI（codex.exe 应可被插件宿主找到），并预先在本地完成模型与提供商配置。ChatGPT 账户自身的 MCP 执行权限仍可能阻止远程调用。

    任务只在 Magpie 插件宿主存活期间维护，当前版本不保证跨重启恢复进行中的任务。请勿用作无人值守生产部署。

    由本地插件读取 Magpie 已向 Codex 开放的供应商模型目录，无需修改 Magpie 本体或复制 ID。
