原生 Codex + ChatGPT 协作

推荐方式 · Magpie Skills 安装 · 无需开启下面的 app-server

Skill

在 Magpie 的 Skills 中从 GitHub 导入 magpie-codex-collab 并指定给 Codex。Skill 使用原生 Codex 执行和已有的 Magpie MCP 连接，不会新开隧道，也不会复制项目文件。

专用 ChatGPT 标签页由 Codex 内置浏览器管理；只有该环境提供 control-in-app-browser 时才能自动发送审核消息。不同对话通过任务 ID、真实聊天 URL、MCP 项目验证后安全切换。

Skill 路径：skills/magpie-codex-collab。GitHub：查看安装源。

两个新工具：chat_session_status、chat_session_request_transfer。后者只提交切换申请，不会直接操纵浏览器。原生 Codex 关闭时也不会自动唤醒 ChatGPT。

本地 Codex 集成（实验性）

只读为安全默认值。修改项目时仅开放 Codex Desktop 中对应工作区；跟随本地权限时可能获得更大范围的文件访问权。

确认允许 Codex 修改项目代码？

提升执行权限必须在本地明确确认。Magpie 不会自动同意 Codex 的权限提升请求，也不会提供直接修改项目的 ChatGPT MCP 工具。

需要在 Windows 上安装可执行的 Codex CLI（codex.exe 应可被插件宿主找到），并预先在本地完成模型与提供商配置。ChatGPT 账户自身的 MCP 执行权限仍可能阻止远程调用。

运行中的任务仍依赖本地插件进程；已完成任务的审核记录保存在本地。

由本地插件读取 Magpie 已向 Codex 开放的供应商模型目录，无需修改 Magpie 本体或复制 ID。
