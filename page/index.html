MAGPIE · CODEX

Codex 桥接

ChatGPT 通过 Magpie 只读访问 Codex Desktop 已登记的项目，并把任务交给本机原生 Codex Desktop 执行。

Codex 协作

关闭时 ChatGPT 只能读取项目文件。需在 Magpie Skills 中安装 magpie-codex-collab。

提升权限只能在此确认，ChatGPT 无法远程更改。

确认允许 Codex 修改项目代码？

Codex Desktop 输入框内容与启动指令一致时点一次发送。没发出去的原因见 chat_session_status。

Agent 双向通信

仅向已在本地注册的 Agent 会话排队发送命令。Harness 在运行中通过 Magpie MCP 读取，回复通过 ego-browser 发往 ChatGPT Web。此开关不授权启动进程或扩大文件访问权限。

远程连接

本机 Cloudflare MCP 适配器（端口 48765）。需已配置 Cloudflare Access 和 Tunnel。
