    ChatGPT 远程连接

    本机管理 Cloudflare MCP 适配器 · 默认仅六个只读工具

    开启一次后，插件将尝试注册当前 Windows 用户的登录自启项（无需管理员权限）。Magpie 运行时自动启用 48765，退出后关闭监听；无需每次运行 PowerShell。

    需要事先配置 Cloudflare Access、安装 Node.js 20+，且 Magpie 与 Cloudflare Tunnel 正在运行。不修改你的 Cloudflare 设置，Codex 工具需在本机单独开启。

    本地 Codex 集成（实验性）

    通过本机 app-server 创建任务、查询结果和取消任务

    默认关闭。只有本机在此启用后，才允许 MCP 下发 Codex 任务；默认只读沙盒。开启写入后使用 Codex workspace-write 沙盒。绝不自动授权提权或批准外部操作。

    需要在 Windows 上安装可执行的 Codex CLI（codex.exe 应可被插件宿主找到），并预先在本地完成模型与提供商配置。ChatGPT 账户自身的 MCP 执行权限仍可能阻止远程调用。

    任务只在 Magpie 插件宿主存活期间维护，当前版本不保证跨重启恢复进行中的任务。请勿用作无人值守生产部署。
